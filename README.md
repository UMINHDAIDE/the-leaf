# The Leaf — website

A responsive, static personal mathematics journal. No paid hosting or build tools are required.

## Publish with GitHub Pages
1. Extract this ZIP on your computer.
2. Open your `the-leaf` repository on GitHub.
3. Upload the **contents** of this folder (`index.html`, the other HTML files, and `assets/`) to the repository root. Do not upload the ZIP itself or a nested `the-leaf-redesign` folder.
4. Commit the changes.
5. In the repository, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**, then select branch `main` and folder `/ (root)`. Save.
7. Your site will appear at `https://YOUR-USERNAME.github.io/the-leaf/`.

## Update the site later
- Edit page text in the relevant `.html` file.
- Edit colours, spacing, and typography in `assets/style.css`.
- Put images in `assets/` and reference them with paths such as `assets/my-image.jpg`.

## Notes
- The layout is responsive for phones and desktop screens.
- Mathematics on `notes.html` is rendered with MathJax from a CDN, so an internet connection is needed for formatted equations.
- Google Fonts are used with system-font fallbacks. The site remains readable if those fonts cannot load.
